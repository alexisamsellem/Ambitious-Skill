# Speed: the same ambition in less time

> "Speed: The same work in less time, the bread and butter for AI's economic value: If you need some code written, I'll do it faster with Claude. Well established and requires little creativity in how you approach AI, so I'll skip this one." (#2, #2b)

The author skips *explaining* Speed because readers already know it, not because it is out of scope. Speed is one of the four dimensions.

**Receives** the target as defined by Altitude, Depth and Range.
**Produces** a plan or artifact that reaches that target in far less time.

**Why Speed runs last.** Run first, Speed only makes the *original* task faster, which is the low-ambition baseline the article starts from. Run last, it compresses an ambition that is already defined.

## Moves

*All Speed moves are proposals (not from the article), except where a `#` is cited. They are validated or rejected by the evals (open question O6).*

| Move | What to do | Basis |
|---|---|---|
| The ×10 question | How would we reach this target in a tenth of the time? | proposal |
| Parallelise | Fields, hypotheses, files, clients or hubs handled by parallel subagents. | #45, re-tagged Speed |
| Tighten the feedback loop | Replace a slow judge with a runnable one that answers immediately. | #35, re-tagged Speed |
| Backtest before waiting | Before "run it beside the current one for a quarter" (#14), prove it on history (#13). That gives an answer in hours instead of a quarter. | #13, #14 |
| Remove human handoffs | A standing outcome or durable workflow means the model doesn't wait to be re-briefed "task after task". | #8, #21, re-tagged Speed |
| Timebox | Put a tight deadline in the plan for the human, and an iteration budget in the model's instruction. | #58 (Collison's "Fast" list); model reading is a proposal (O7) |

Like every escalation, each Speed move names the goal it serves and its judge (G1). Example: `Timebox: reply requested before 17:00. Goal served: rung 2 (a firm date today). Judge (c): a dated reply received before 17:00.`

## When it applies

Always, as the final pass. It runs standalone only when Alexis explicitly asks for "faster".

## When it is dropped

When the duration is the value itself: an observation that has to span a full cycle, a cooling-off period, a legal delay. One-line reason: `Speed dropped: the 12-month observation window is the point of the study.`
